## 独立站服务器需要什么配置

刚起步的独立站，1GB 内存能跑 WordPress，但装了 WooCommerce、缓存插件和几个营销插件之后，2GB 会从容很多——官方对自家一键应用给出的内存参考也印证了这个量级：n8n、Coolify 这类工具 2GB 起步舒服，Ollama、AnythingLLM 这类要 4GB 起。对独立站来说，比内存更重要的是三件事：

- **机房位置**：访客在哪，服务器就放哪附近。外贸独立站访客多在欧美，美国机房是主流选择；如果有较多大陆访问，选西海岸。
- **月流量**：图文为主的独立站 3TB 月流量能撑日均几万 PV；产品图、视频多的站往大档位看。
- **KVM 架构**：资源隔离有保障，不会被同机邻居拖垮，这一点比省几美元重要。
